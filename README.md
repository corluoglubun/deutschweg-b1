# Deutschweg B1

Eine browserbasierte Lernanwendung zum Üben deutscher Vokabeln und Sprachkenntnisse.

**Technologien:** HTML, CSS und JavaScript.

## Funktionen

- Lernkarten für 30 Vokabeln mit zeitlicher Wiederholung.
- Vokabeltests mit Noten und Ergebnisübersicht.
- Deutsche Beispielsätze und kurze Lesetexte mit türkischer Unterstützung.
- Lernfortschritt und lokale Speicherung im Browser.
- Export und Import von Lernständen.

## Projektkontext

Entstanden als persönliches Praxisprojekt während meiner Umschulung zum Fachinformatiker für Anwendungsentwicklung, mit KI-Unterstützung. Meine Beiträge umfassen Anforderungen, Funktionsplanung, Priorisierung und Gestaltungsvorgaben. Die technische Umsetzung, Tests und Dokumentation wurden umfangreich KI-gestützt erstellt.

## Start

Die Projektdateien herunterladen und gegebenenfalls die ZIP entpacken. Anschließend `index.html` im Browser öffnen.
